# Google-clone
A simple **Google-clone** built with **HTML** and **CSS**.  
This project replicates the look and feel of the Google search page with a logo, search bar, and action buttons.

---

## ✨ Features
- Centered Google logo
- Search bar with placeholder text
- "Google Search" and "I'm Feeling Lucky" buttons
- Hover effects for buttons
- Responsive and minimal design
